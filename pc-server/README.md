# PC server

Python UDP listener that turns Hinge Pad packets into a virtual Xbox 360 controller via [vgamepad](https://github.com/yannbouteiller/vgamepad) / ViGEmBus.

```text
python server.py
python test_client.py demo
python -m pytest tests
```

See the root [README](../README.md) for install, firewall, and emulator steps.
